# SYN Study · Математический анализ

Курс на два года, четыре семестра: 26 учебных глав, 130 практических задач, 130 вопросов самопроверки, 73 разобранных примера и 14 управляемых моделей. Первый год следует программе В. С. Белоносова (НГУ, 2014/2015), второй — официальной программе НГУ, составитель С. К. Водопьянов. Это краткое оригинальное изложение SYN с определениями, условиями теорем, выбранными доказательствами и задачами; оно не заменяет полный лекционный курс и не приписывается составителям программ.

[Открыть курс](https://troglobiont.github.io/syn-study/) · [Скачать Android APK](https://github.com/troglobiont/syn-study/releases/latest)

## Web и Android

Веб-версия публикуется из dist/ через GitHub Pages. Android APK собирается из тех же файлов: все уроки находятся внутри приложения, сайт для занятий не загружается.

У Android свой локальный прогресс. Перенос с сайта — «Данные → Экспортировать прогресс», затем импорт JSON в приложении. Сохранение и выбор файла используют системный интерфейс Android. Широкие разрешения на файлы, сеть, камеру и контакты не запрашиваются.

Android: пакет io.github.troglobiont.synstudy, версия 1.3.0 (5), Android 7.0+ с актуальным Android System WebView. В Releases выберите SYN-Study-Android.apk и откройте файл на телефоне. Подписанный установщик публикуется после проверки сборки; рядом находится SHA-256. Обновления и JSON из 1.0.0–1.2.0 сохраняют прогресс. Старые тесты сохраняют наборы из 10, 30 или 75 вопросов; новые содержат 130. Идентификаторы и ответы всех прежних задач сохранены. Новые основы поставлены перед темами, которые на них опираются.

## Программа

Первый год: [программа В. С. Белоносова, разделы I–XI](https://studfile.net/preview/6307749/). Второй год: [официальная программа НГУ, семестры 3–4, С. К. Водопьянов](http://old.math.nsc.ru/~matanalyse/PROGR02.pdf), разделы 13–19. Авторство второй программы указано отдельно и не переносится на Белоносова.

1. Семестр 1: множества, функции, вещественные числа, последовательности, предел и непрерывность, производная.
2. Семестр 2: числовые ряды, интегралы одной переменной, пространство ℝⁿ, пределы и дифференцирование отображений.
3. Семестр 3: подготовительная глава SYN о функциональных рядах; высшие производные, обратные и неявные отображения; многообразия, Лагранж; мера и интеграл Лебега, Фубини, замена переменных, параметры, Γ и B.
4. Семестр 4: равномерные несобственные интегралы, произведения, свёртка и сглаживание, Вейерштрасс; мера Хаусдорфа, площадь и кообъём; формы, ориентация и Стокс; ряды и преобразование Фурье, Планшерель и уравнение теплопроводности.

S3-P — обозначение подготовительной главы SYN, а не номер раздела программы Белоносова. Все учебные тексты и задачи написаны для приложения. Старые идентификаторы и ответы сохранены. Для каждого нового раздела есть теория, три разобранных примера, практика и самопроверка.

## Разработка

Веб-приложение не требует npm-зависимостей:

    python3 -m http.server 3810 --bind 127.0.0.1 --directory dist

Открыть http://127.0.0.1:3810/ . Проверки ядра: node --test tests/*.test.js.

Для Android нужны JDK 17+, Gradle 8.14.3 и Android SDK 36:

    gradle -p android assembleRelease

Задача bundleWebAssets включает dist/ в APK. CI собирает release без подписи и выполняет instrumentation-тесты на Android Emulator. Закрытый ключ SYN хранится отдельно от репозитория; для последующих версий нужен тот же ключ и больший versionCode.

## Учебные и технические границы

Произвольные доказательства не оцениваются автоматически. Первая попытка, подсказка, просмотр ответа и исправление учитываются раздельно. Сохранение итогов главы отмечает их просмотр и не изменяет результаты задач.

Источники доступны по ссылкам внутри приложения. Материал и векторная графика оригинальные. Персональный бэкграунд и результаты пользователя не входят в репозиторий. Нет аккаунта приложения, облачной синхронизации, рекламы и аналитических трекеров. Удаление данных приложения удаляет локальную историю, поэтому полезен экспорт.

Android использует WebViewAssetLoader из AndroidX WebKit (Apache 2.0): https://developer.android.com/develop/ui/views/layout/webapps/load-local-content . Физические устройства и интерес к подаче проверяются отдельно от технической сборки.
